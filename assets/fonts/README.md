# Bundled thumbnail-browser font

`PretendardVariable.ttf` is Pretendard 1.3.9 from the official [orioncactus/pretendard release](https://github.com/orioncactus/pretendard/releases/tag/v1.3.9). Q1View loads it privately for thumbnail-browser UI text; it is not installed as a system font.

The font is distributed under the SIL Open Font License 1.1. Keep `Pretendard-LICENSE.txt` with every packaged copy of the font.
